Mechanical Engineering Design I, II - 3DoF Pan-Tilt System

This was part of the Senior Capstone Design Project. The aim of this project is to build an effective camera system that can track objects in any direction. To track object, rather than implementing complex algorithms for object detection, it would be better to detect color of an object.

Results

There were several constraints like low resolution of the camera, and wire tangling problem when rotating. In order to solve those problems, my team came up with multiple concept designs.

Also, the initial objective was to build a 3DoF machine, but my team couldn't successfully design the roll rotation which would allow the camera to rotate due to wire tangling problems.
